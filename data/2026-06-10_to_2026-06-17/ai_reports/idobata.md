## 新たに作成されたPR

### [PR #497](https://github.com/digitaldemocracy2030/idobata/pull/497) トップページ表示と GitHub App 秘密鍵設定を改善

- 作成者: 101ta28
- 変更内容: 12ファイル (+229行 / -118行)

#### 主な変更点
- 「最新の質問がない場合」でも最新テーマを表示し、スムーズにページ遷移できるように調整
- 質問カードやテーマカードなどのUI部品が柔軟にリンク先を受け取れるように改修
- フロントエンドの共通HTTPクライアントでGETリクエストに「cache: 'no-store'」を指定し、最新情報を優先的に表示
- GitHub Appの秘密鍵を環境変数・base64形式、または任意パスのファイルから読み取れるようにし、運用の利便性を高める
- GitHub関連の環境変数を出力していたデバッグログを削除し、セキュリティ面を向上
- `idea-discussion` のスキーマとTypeScript型に拡張を加え、Problem / Solution / SharpQuestionなどのデータ構造を整備

#### レビューしてほしいポイント
- スキーマや型変更が既存データやAPI利用箇所に影響を与えないか
- GETリクエストを常に「no-store」で取得する方針のパフォーマンス面への影響
- GitHub App秘密鍵の読み込み手順が運用やローカル開発で扱いやすいか
