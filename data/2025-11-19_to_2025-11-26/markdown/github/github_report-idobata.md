## 解決・改善したいこと

現在、**コメントが無効**の状態でも「話題を変える」ボタンを押せてしまい、ユーザーにとって挙動が分かりにくい／期待と異なる印象があります。  
以下のいずれか、または複合的に改善できないでしょうか。

*   **A案：通知メッセージを表示**  
    必要であればテーマ説明の補助メッセージ（例：「承知いたしました。今回のテーマは…」）は**コメント有効時のみ**出すよう条件分岐。

*   **B案：ボタンをグレーアウト（disabled状態）**  
    コメント無効時は「話題を変える」ボタンを**押せない**状態にする（ホバー時ツールチップで「現在コメントは無効です」を表示すると親切）。

*   **C案：押してもAPIを叩かない**  
    見た目は押せるままでも、コメント無効時は**API呼び出しをスキップ**してクライアント側で通知のみ表示。
