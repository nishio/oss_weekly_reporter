1. *ガイド冒頭の分岐を変える（すぐできる docs 修正）*
個人・小規模団体：これまでどおり Docker Desktop
自治体・大きな組織：WSL2 + Docker Engine の手順へ案内
「政府機関は有料」と規約へのリンクを明記する
Docker Desktop を完全に外さない理由は、非専門家にとって一番失敗しにくい方法であることは変わらないからです。西尾さんの「外していく方向」とは、ここだけ少し違う提案になります。
2. *WSL2 + Docker Engine の手順書は、大木さんの実際の手順から作る。* 以下の点で詰まりやすいので、大木さんに具体的な手順を出してもらうのが近道です。
Ubuntu のバージョンと、Docker の入れ方（`docker-ce` か Ubuntu の `<http://docker.io|docker.io>` か）
リポジトリを WSL 側に clone すること（Windows 側だと CRLF で `.sh` が壊れる）
systemd、`.wslconfig` でのメモリ設定、庁内プロキシ
前提として、`wsl --install` に Windows の管理者権限と仮想化の有効化が要るのは Docker Desktop と同じなので、権限の問題がなくなるわけではありません。
3. *「（未検証）」ラベルの件は別 issue にする。* o4-mini は動いたという報告で、既存の #912 / #913 と同じ流れの検証タスクです。
4. *WSL 3 は `wslc compose` が出てから再評価する。* 今は wiki の Open Questions に記録しておく程度で十分です。
