### [画像の前処理モジュールを追加してOCR精度を向上させる](https://github.com/digitaldemocracy2030/polimoney/issues/95)

**作成者:** ymori1212  
**作成日:** 2025-05-27T13:53:34Z  
**内容:**

## 解決・改善したいこと

現在 `tools/pdf_to_images.py` で PDF をページごとに PNG へ変換し、そのまま `analyze_image_gemini.py` に渡して OCR 処理を行っています。

OCRの認識精度は入力画像の品質に大きく左右されることが知られています。画像のコンディションによっては期待する精度が得られない場合があるため、より安定した高い認識精度を目指し、OCR処理の前に画像前処理ステップを導入することで画質の改善を図りたいです。

## 具体的な実現方法・実装方法の概要

- `tools` 配下に `preprocess.py`（仮称）を新規作成し、グレースケール化・二値化・ノイズ除去などの前処理機能を提供する
- `pdf_to_images.py` に `--preprocess` オプションを追加し、PDF 変換直後に前処理を実行できるようにする
- 前処理済み画像を `output_images/processed/` に保存し、同ディレクトリに前処理内容を記録したログファイルを出力する
- 基本的な前処理を優先して実装し、効果を確認しながら必要に応じて処理内容を拡張する
