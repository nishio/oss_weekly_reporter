1.  各種 Typography の命名規則（ex. heading/lg, body/md/bold, body-bold/md など）
2.  Figma と Chakra UI のプロパティをどこまで揃えられるか
2 については、フロントエンドで利用している Chakra UI の観点でお話しすると、Typography を定義できる Text Styles というレイヤがあるので、こちらに Typography ごとに font-size, font-weight, line-height, letter-spacing などを定義していくことになりそうです。
検証は必要ですが、こちらを定義すると以下のように実装できるイメージを持っています。

```// textStyleの命名規則は仮です
// textStyleが定義できれば、font-size,line-heightなどの個別に宣言が不要になる
<Text textStyle="heading/lg">Heading Text</Text>
<Text textStyle="body/md">Body Text</Text>```
これは nice to have の観点ですが、Figma でも textStyle というプロパティがあって、それを設定すると Typography 関連のプロパティが設定できるようになると、textStyle をインターフェースにして Figma（デザイン） と Chakra UI（フロントエンド） の Typography の定義やスタイリングの足並みを揃えられそうかなと思いました。
