## 概要

DD2030 の Slack には、広聴AI・いどばた等の活用事例が投稿されることがあります。

例えば [#1_事例紹介_全体](https://dd2030.slack.com/archives/C08LJ9T5MLY) チャンネルには、各地での取り組みや関連サービスの紹介が流れていますが、現状ではそれらが website に反映されるかどうかは手作業に依存しています。

Slack 上に投稿された事例をもとに、AI を使って website の適切な箇所を更新する Pull Request を作成できると良さそうです。

## できると良さそうなこと

- Slack の事例投稿をもとに、掲載候補の内容を整理する
- 広聴AI / いどばた / Polimoney / topics など、反映先の候補をAIが提案する
- website リポジトリへの更新 PR を作成する
- 人間が内容を確認してからマージする
